### ❗Copy all the `libraries` to the project's `lib` folder.

```
Project/
├── lib/
│   ├── Audio_ES8311/
│   ├── Audio_PCM5101/
│   ├── BAT_Driver/
│   .
│   ├── lvgl/
│   └── ui/
├── src/
│   └── main.cpp
```

### Music Player:
Change the hardware version in `platformio.ini`
```ini
; Select hardware version: V1 or V2
[platformio]
default_envs = V1
```
